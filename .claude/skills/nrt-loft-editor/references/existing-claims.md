## 衝突が起きやすい箇所

| 状況 | 対処 |
|---|---|
| 紙を推した後に画面の記事を書く | 「例外」として位置づける。紙を否定しない |
| 「公開しなくていい」と書いた後にレンタルスペースの話 | 矛盾を先に認め、順番は同じだと示す（まず自分用、需要があれば後から） |
| 「分類をやめた」と書いた後にツールが増えて分類が発生 | 皮肉として書く。L13の一番強い部分になる |
| 「小さく作る」と書いた後にツールが増えて困る | 方針は変えない。増えたこと自体が問題だと書く |
| 「買わなくていい」と書いた後に3Dプリンター等の機材の記事 | 冒頭に「これは機材が必要な回です」と明記。なくてもできる方法を添える |
| 「機材が要る」記事にアフィリエイトを置く | T3（買わなくていい）には置かない。T4（買うなら）には置いてよい。この方針の違いを記事内で説明できる |
