## 条件が揃わないと書けない記事

| 記事 | 必要な条件 |
|---|---|
| L5 30日後、使っていなかった | 作成から30日以上経過し、実測している |
| L13 ツールが3つ | ツールが3つ以上あり、実際に混乱が起きている |
| T11 枠を使い切った月 | 3ヶ月以上（できれば6ヶ月）の使用量ログ |
| T3 いま家にあるPC | 古いPCでの実機検証が完了している |
| T9 スマホしかない人 | スマホのみでの検証が完了している |
| T6 妻に渡した | 実際に渡している |
| B1 プリント管理アプリを全部やめた | 既存アプリ（プリゼロ、ポスリー、まなびの手帳）を実際に触っている |
| L6 作らなくていいと言われた | 実際にそのやり取りが発生し、ログがある |
| J3 1ヶ月目の数字 | 開始から1ヶ月経過 |
| L12 Before写真がなかった | 実際に素材の取り漏らしが発生している |

**これらを条件が揃わないまま書いていたら指摘する。** 想像で書いた記事は、シリーズの差別化（実体験）を損なう。

## 公開時期に制約がある記事

| 記事 | 適した時期 | 理由 |
|---|---|---|
| B12 保護者会の日程を1枚に | 4月 | 年間行事予定が配られる時期 |
| B15 年賀状の住所録 | 11月〜12月上旬 | それ以外だと検索需要から外れる |
| B4 夏期講習プリント | 6〜7月 | ただし「長期休みと定期テスト」に広げれば通年可 |
| B5 旅行のしおり | 6〜8月 | ただし通年でも成立 |

**時期を外して公開する場合、内容を広げる指示を出す。** B4なら「夏休み」に限定せず「長期休みと定期テスト」にする。
