2026年9月時点の、自分の契約の話です。一般論ではありません。

このサイトで紹介している小さな仕組みは、ほとんど Claude Code で作っています。
Claude Code は、Anthropic の AI「Claude」の有料プランに入っている道具です。

有料プランには、月20ドルのものと、月100ドル・200ドルのものがあります。
「どれにすればいいですか」と聞かれることがあるので、自分の場合を書いておきます。

## プランの違いは「使える量」

Claude の個人向けの有料プランは、次の3つです。

- Pro：月20ドル
- Max：月100ドル（Pro の5倍の使用量）
- Max：月200ドル（Pro の20倍の使用量）

どれを選んでも Claude Code は使えます。
上のプランにしても、できることが増えるわけではありません。増えるのは、使える量です。

![机の上に置かれた砂時計](/images/20-dollars-or-100-dollars/hourglass.webp)

*写真：Milad Fakurian / Unsplash*

使える量には、5時間ごとの枠と、1週間ごとの上限があります。
5時間の枠は、最初にメッセージを送ったときから数え始めます。

枠を使い切ると、そこで作業が止まります。
あとは時間が経って枠が戻るのを待つか、プランを上げるか、追加の利用分を買うかです。

どれくらい使ったかは、Claude の設定画面にある使用量の項目で確認できます。

## 自分が上げてきた順番

最初は Pro の20ドルで始めました。
そのあと、2025年に Max の100ドルに上げています。

2026年2月からは、200ドルのプランです。
100ドルに上げたあとも、使用量の上限に当たって止まる回数が増えてきたからでした。

100ドルにすれば足りると思っていましたが、そうはなりませんでした。
上げても、使い方が変わらなければ、また同じところで止まります。

## 分かれ目は、何を作るかより「どれだけ触るか」

作るものの難しさで、プランは決まりませんでした。
効いてくるのは、1日にどれだけ触るかです。

![付箋が貼られた壁と、ノートパソコンが置かれた机](/images/20-dollars-or-100-dollars/desk-notes.webp)

*写真：Richard Stachmann / Unsplash*

夜に少し触って、その日のうちにやめるなら、枠を使い切る前に作業が終わります。
休日にまとまった時間座ると、途中で枠が尽きて止まります。

作りかけの本数も効きます。
1本ずつ仕上げるなら、触る量はそれほど増えません。
何本も並行して、行き詰まったら別のものに移る進め方をしていると、1日に使う量はそのまま増えていきます。

## 20ドルなら、Codex という選択肢もある

20ドルで考えるなら、ChatGPT の Plus（月20ドル）に入っている Codex も候補になります。
自分も使ったことがあります。

Codex の使用量は、ChatGPT の普段の利用と同じ枠を分け合う形です。
どちらが合うかは、使う量と、普段どちらの AI を使っているかで変わると思います。

## これから始めるなら

最初は20ドルで十分です。
止まって困るようになってから上げても、遅くはありません。

先に上のプランにしても、止まる回数が減るだけで、作れるものが増えるわけではないからです。
