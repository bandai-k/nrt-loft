2026年9月時点の、自分の契約と家の話です。一般論ではありません。

Claude Code に、毎月200ドル払っています。

知り合いにこの金額を言うと、たいてい「高いね」と返ってきます。
月額のサービスとして聞けば、そう感じるのは当然だと思います。

それでも解約していないのは、比べている相手が違うからです。

## いまの契約

![夜の机に置かれたノートパソコンとスタンドライト](/images/fixed-cost-and-claude-code/laptop-night.webp)

*写真：Fujiphilm / Unsplash*

使っているのは、Anthropic の Claude の Max プランです。
2025年に月100ドルのプランで契約して、2026年2月から月200ドルのプランにしています。

公式の料金ページでは、個人向けのプランは次のようになっています。

- Pro：月20ドル（年払いなら年200ドル）
- Max：月100ドルから。Pro の5倍か20倍の使用量を選ぶ

Pro も Max も Claude Code を使えます。表示されている金額は税抜きです。

ドルで払っているので、円にすると毎月の金額は為替で変わります。

## 「高いね」と言われるとき

![動画のサムネイルが並ぶ画面の前に置かれたスマートフォン](/images/fixed-cost-and-claude-code/streaming.webp)

*写真：BoliviaInteligente / Unsplash*

動画配信や音楽のサブスクと同じ棚に置けば、200ドルは桁が違います。
その物差しで見るなら、自分も高いと思います。

ただ、自分がこのお金で買っているのは、見るものや聴くものではありません。
家の困りごとを片づける、小さな仕組みです。

## 比べているのは、人に頼んだ場合

このサイトで書いてきたものは、どれも自分の家のために作りました。

- [冷蔵庫の中身を管理するツール](/build/fridge-inventory)
- [学校のプリントを撮るだけで予定にするツール](/build/school-print-to-calendar)
- [買い物リスト](/build/shopping-list)

これを人に作ってもらったらいくらになるか。
見積もりを取ったわけではないので、発注サイトが公開している相場を見ました。

ランサーズの発注者向けの記事では、ツール系のアプリを外注する場合の相場が50万〜300万円とされています。

とはいえ、自分が作ったものは、そこで想定されているアプリよりずっと小さいです。
使うのは家族だけで、見た目も最低限です。
相場の下限をそのまま当てはめるのは、正直かなり乱暴だと思います。

それでも、仮に1本50万円としたら、月200ドルの1年分前後になります。
しかも人に頼んだものは、家の事情が変わるたびに直してもらう必要があります。

## 固定費として並べてみると

![電卓と請求書が並んだ机](/images/fixed-cost-and-claude-code/bills.webp)

*写真：Giorgio Tomassetti / Unsplash*

家でよく見かけるサブスクを、月額で並べてみます。

- Netflix（スタンダード）：1,590円
- Spotify Premium（Standard）：1,080円
- YouTube Premium（個人）：1,280円
- iCloud+（200GB）：540円

4つ全部入っていても、月4,490円です。

月200ドルは、この組み合わせの何セット分にもなります。
固定費の一覧に並べれば、見直すときに真っ先に目に入る金額です。

それでも残しているのは、上に書いたとおり、比べる先が動画や音楽ではないからです。

## それでも高い月はある

何も作らない月があれば、その月の200ドルはただの出費です。

契約した時点では、高いか安いかは決まりません。
その月にいくつ困りごとが片づいたかで、あとから決まります。

「高いね」と言われるのは、これからも変わらないと思います。
月額のサービスとして見れば、実際に高いからです。
