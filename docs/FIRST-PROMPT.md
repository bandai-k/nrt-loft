# Claude Code への最初の指示（コピペ用）

以下をそのまま Claude Code に貼る。

---

このリポジトリで NRT LOFT というメディアを運営します。
記事企画とメディア戦略は別セッションで詰めてあり、その結果を HANDOFF.md にまとめました。

まず HANDOFF.md を読んでください。そのうえで、以下を順に進めてください。

## 1. 現状確認

`src/` の中を確認して、以下を教えてください。

- 記事一覧を持つ構成になっているか、静的な1枚ものか
- App Router のルーティング構成
- 使っている Tailwind のバージョン

あわせて、以下の3点が意図的なものか、作業途中の残骸かを判定してください。

- `NrtLoftSite.jsx` がルート直下にある
- `postcss.config.js` と `postcss.config.mjs` が両方ある
- `nrt-loft-renewal/` ディレクトリがある

## 2. Skill の配置

添付した `nrt-loft-editor` を `.claude/skills/nrt-loft-editor/` に配置してください。
記事を書いたら、または受け取ったら、このSkillで自己チェックする運用にします。

## 3. 記事の置き方を決める

44本の記事を出す前提の構成が必要です。選択肢を整理して、推奨を1つ出してください。

- MDX / Markdown ファイルベース
- Notion API で企画DBから引く
- その他

判断材料：
- 記事本文はリライト後に確定する（いまは草案）
- 記事間の内部リンクが多い（シリーズとして相互参照する）
- カテゴリ別の一覧ページが必要（BUILD / LEARN / TOOLKIT / JOURNEY）
- 各記事に「狙う検索キーワード」がある（SEOが重要。ブランド名では検索されない）
